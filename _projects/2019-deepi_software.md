abstract: >-
  DEEPi is a low-cost deep-sea camera and computer built on the Raspberry Pi,
  potted in epoxy, and tested past 5000 m. I was the principal developer of
  its open-source software, which handles capture, configuration, and live
  streaming over a single network link. The same software runs a four-camera
  array for multi-view imaging and has been used on landers, moorings, drop
  cameras, a fiber optic tether, and student projects. Derived versions are
  sold by JUICE Robotics.
